    How it works
    
    
      
      
    1. 
        
        Runs on your PCThe server listens on 127.0.0.1:18777. Localhost only, never the internet.
      
      2. 
      
    2. 
        
        Claude Code and Antigravity hooks report inInstalled once with npm run setup, so every project on this PC reports here: permission requests, tools, and when work stops.
      
      3. 
      
    3. 
        
        Permission opens the islandWith a sound and a notification. Allow or Deny goes straight back to Claude.
      
      4. 
      
    4. 
        
        Activity, liveWhich file Claude is reading, which command it is running, in which project.
      
      5. 
      
    5. 
        
        Done turns greenWith a chime, so you can keep working without watching the terminal.
      
      6. 
    
    
    
    The island never allows anything on its own. If you don't answer within 4:30, Claude shows its normal terminal prompt. To connect Claude Code, add the hooks from the README to ~/.claude/settings.json.
